# Start Here

1. Open a terminal in this folder.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.
5. The app starts with sample JSON already loaded.
6. You can also upload `public/sample.json` to test file upload.

## Best features to test

- Click **Format** and **Minify**.
- Click nodes in **JSON Explorer** and copy their JSONPath.
- Generate/inspect the **JSON Schema**, edit the test payload, then validate it.
- Use the prefilled **JSON Compare** section and click **Compare JSON**.
- Change the TypeScript root type name and download `.ts`.
- Download formatted JSON or convert compatible data to CSV.

No API key, backend, database, or paid service is needed.
